# Тест-кейсы

| ID | Канал | Синтетическое значение | Ожидаемый результат |
| --- | --- | --- | --- |
| S-001 | Git-файл → push | API-like canary | Обнаружение и маскирование |
| S-002 | Новый Git-файл → повторный push | Тот же API-like canary | Проверка повторного обнаружения |

Для каждого запуска фиксируются время, идентификатор события, категория,
уровень риска, действие и наличие маскирования.
