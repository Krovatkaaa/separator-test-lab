# Separator Test Lab

Изолированный репозиторий для прозрачной проверки DLP/секрет-сканера.

## Правила

- Используются только вымышленные тестовые значения.
- Каждое значение сопровождается описанием ожидаемого события.
- Тесты не предназначены для обхода или отключения защитных механизмов.
- Реальные ключи, токены и персональные данные добавлять запрещено.

## Тест №1 — синтетический API-ключ

Файл `fixtures/synthetic-api-key.env` содержит вымышленный canary-маркер.

Ожидание: сепаратор фиксирует секретоподобное значение при `git push`, указывает
канал передачи и маскирует само значение в журнале.
